# Instructions pour Claude Code

Travail en équipe de 3, à tour de rôle. Le plan en cours est dans `PLAN-TD2-ETAPE2.md` à la racine du dépôt.

Quand on te demande de « faire l'étape suivante » (ou de continuer le plan) :
1. `git pull`.
2. Lis `PLAN-TD2-ETAPE2.md` en entier, puis fais **uniquement la première étape non cochée** (`- [ ]`).
3. Suis le protocole décrit en haut du plan : cocher l'étape, mettre à jour « Résultats déjà acquis », écrire la section du rapport `td2/reports/td2.md`, commit puis push.
4. Pas de ligne `Co-Authored-By: Claude` dans les commits.
