## Results

| Panel | Correct consensus | Wrong consensus | Abstentions |
|---|---|---|---|
| Fixed 2-of-3 (gpt-oss-120b, Cohere, Qwen) | 16/20 | 1/20 (C10) | 3/20 (C15, C17, C19) |
| 3-of-5, exploratory (two gpt-oss models) | 16/20 | 1/20 (C02) | 3/20 (C10, C15, C17) |

**Wrong consensus C10**: Cohere and Qwen both return 119 410 (reference 558 980); both miss the orders placed before the 26th birthday in the following calendar year. The delta query finds 4 customers and 439 570 cents.

**Routing rule**: first model Cohere for period and product questions (all five models at 100 %, provider other than Groq), Qwen for age at a date, gpt-oss-120b for age at the order and combinations (only the two gpt-oss models right); checks by use (dashboard, customer figure, payout); fallback, defer, paid route or abstain.

## Reproduce

From this folder, with the virtual environment at the repository root:

```powershell
..\.venv\Scripts\Activate.ps1
python atelier-vote.py                                            # 4 synthetic examples
python atelier-vote.py --traces ../td1/traces-td1.csv --case C10  # wrong consensus; C15 abstains
python compare-vote.py                                            # table of the 20 decisions
python sql/relecture.py                                           # 36 checks of section 2
python atelier-routage.py      > simulator-before.jsonl
python atelier-routage-new.py  > simulator-after.jsonl
python compute_accuracy.py
```
